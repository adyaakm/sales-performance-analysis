# Sales Performance Analysis Dashboard

## Overview

This project analyzes sales transaction data to understand revenue, profit, product,
category, customer, and regional performance.

The project demonstrates a practical data-analysis workflow using structured sales
data, SQL queries, Excel, and dashboard-oriented visualization.

## Objectives

- Analyze overall sales and profitability.
- Identify monthly revenue trends.
- Compare regional performance.
- Evaluate product and category contribution.
- Identify high-value customers.
- Prepare insights that can support data-driven business decisions.

## Technologies Used

- SQL
- Microsoft Excel
- Power BI
- Data Analysis

## Dataset

The dataset contains sales transactions with fields including:

- Transaction ID
- Order Date
- Region
- Category
- Product
- Customer ID
- Quantity
- Unit Price
- Discount
- Revenue
- Cost
- Profit


## SQL Analysis

The SQL script contains queries for:

- Overall revenue, cost, and profit
- Monthly revenue and profit
- Regional performance
- Category performance
- Top products
- Customer contribution

## Dashboard

The dashboard is designed around the following KPIs and views:

- Total Revenue
- Total Profit
- Total Orders
- Units Sold
- Monthly Revenue Trend
- Revenue by Region
- Revenue by Category
- Product Performance


## Business Questions

The analysis focuses on questions such as:

1. What is the overall revenue and profit?
2. Which regions generate the most revenue?
3. Which categories perform best?
4. Which products contribute the most revenue?
5. How does revenue change month over month?
6. Which customers contribute the most revenue?

## Insights
The analysis can be used to identify high-performing regions, categories and products,
observe sales trends, and support data-driven decision-making.
